# 保留的压测结果

这里只保留两次正式端到端结果。账号、JWT 和群关系保存在本地 `data/load-fixture-10000x1000/`，不提交到 Git。

## 本地最佳结果

目录：[`local-best/`](local-best/)

- 10000 个连接，三台 Gateway。
- 100 个群，每群 100 人，其中 10 人各发送 1 条/秒。
- 120 秒发送 119999 条入站消息，服务端完成 11999900 次广播投递，约 10 万次投递/秒。
- 客户端完整解析 11999900 条，缺失 0；握手失败、Socket 错误、提前断连、服务端写错误和队列丢弃均为 0。
- Gateway 内部平均延迟 80.94 ms；出站帧最老消息 P95 190.87 ms、P99 273.86 ms。该延迟不含客户端解析和网络 RTT。

## 云端最佳结果

目录：[`cloud-best/`](cloud-best/)

- 阿里云部署，10000 个静默 WebSocket 连接。
- 108.522 秒达到满连接，随后保持 600 秒。
- 保持窗口 235 次服务端采样的最低活动连接均为 10000。
- 握手失败、重连、Socket 错误、提前断连和 Gateway 读取超时均为 0。
- 三台 Gateway 分布为 3333、3333、3334。
- 专用 Go 连接器限制为 512 MiB/1 CPU，内存峰值 231.7 MiB。

云端连接器运行在 ECS 本机，用于验证服务端连接容量和稳定性，不代表手机热点或公网链路能够承载相同连接数。

每个目录均保留 `report.md`、`analysis.json`、`run.json`、客户端汇总、容器采样和原始 Gateway/Prometheus 指标，能够重新核对报告中的统计结果。
